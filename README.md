# IA_projeto



##  Como Executar o Projeto

Após clonar o repossitorio siga os seguintes passos:

### 1. Acesse o diretório do código
No terminal, navegue até a pasta `src` (ou a pasta raiz onde estão os arquivos do projeto):
```bash
cd src
```

### 2. Crie o ambiente virtual (venv)
Execute o comando correspondente ao seu sistema operacional para criar o ambiente:
```bash
python -m venv venv
```

### 3. Ative o ambiente virtual
Ative o ambiente baseado no seu sistema e terminal atual:

* **Windows (PowerShell):**
  ```powershell
  .\venv\Scripts\Activate.ps1
  ```
* **Windows (CMD):**
  ```cmd
  .\venv\Scripts\activate.bat
  ```
* **Windows (Git Bash) / macOS / Linux:**
  ```bash
  source venv/bin/activate
  ```

*(Você saberá que deu certo quando ver `(venv)` no início da linha do terminal).*

### 4. Instale as dependências
Com a venv ativa, instale todas as bibliotecas necessárias listadas no arquivo:
```bash
pip install -r requirements.txt
```

### 5. Execute o projeto
rode o arquivo para colocar o projeto rodar:
```bash
python projetoia.py
```
Após isso você pode acessar o site por meio do link que esta no terminal
